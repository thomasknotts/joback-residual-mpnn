JR-MPNN Architecture

The Joback-Residual Message Passing Neural Network (JR-MPNN) is a hybrid graph neural network that combines classical Joback group-contribution estimates with a data-driven residual correction. Predictions follow the form:

ŷ = yJoback + r̂(G, c)

where G is the molecular graph and c is the Joback conditioning vector [yJoback, g1, …, g41].

Key Design Choices

Triple Pooling

Global add + mean + max pooling concatenated into a single embedding — captures size, density, and dominant features simultaneously.

XOR Backtracking Prevention

Directed message passing prevents messages from immediately reversing along the same bond, improving long-range communication.

Joback Conditioning

Functional group counts concatenated directly into the readout MLP, anchoring predictions to interpretable thermodynamic baselines.

Conformal UQ

Adaptive prediction intervals via embedding-norm difficulty estimation, providing 95% marginal coverage guarantees.

Data & Training

All models trained on DIPPR 801 data with 5-fold cross-validation. Conformal calibration performed on a held-out calibration split (never seen during training). The model is intended for organic compounds within the DIPPR chemical space.
